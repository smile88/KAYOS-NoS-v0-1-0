# Key Art

Full illustrated narrative scenes — locations and historical events — matching PART 2 of
`docs/Master_KeyArt_Prompts.md` and the timeline in `docs/Canon_Notes.md`. These are painterly
splash/hero illustrations, not Meshy 3D-generation inputs, so they don't belong in
`environment_turnarounds/`.

```
locations/          Astra'Thalas, Khaz-Toruk, Lunaris — canon places with illustrated key art
                     rather than (or in addition to) a walkable-zone Meshy pipeline.
historical_events/  The Night of Silence (the activation), the Great Reversal, the Great
                     Discovery, Northreach's Tear (the 1453 AO disaster), Black Crag & the Last
                     Orc Rebellion.
```

`khaz_toruk_gen2_unconfirmed.png` is a second possible Khaz-Toruk generation (matching purple
Nullzone-crack tower motif from `docs/Canon_Notes.md`) found under a generic filename — plausible
but not as clean a match as `khaz_toruk_gen1.png`. Worth a human look before treating it as
confirmed; follow the `_genN` convention from `art/environment_turnarounds/README.md` if more
generations of any of these show up.
