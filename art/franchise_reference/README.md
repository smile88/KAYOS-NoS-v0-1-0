# Franchise Reference (not this repo's canon)

Per `docs/Canon_Notes.md`: *KAYOS: The Night of Silence* (this game) is one prequel entry in a much
larger "KAOS/KAYOS: Pieces of Fate" franchise, grounded in a master lore set the user keeps outside
this repo (world gazetteer, full race/faction compendium, canonical world history timeline).

The files in this folder are from that broader franchise — world maps, an exotic race roster far
beyond the five factions this game actually uses, and continent-scale political material. **None of
it is Night of Silence canon.** It's kept here only because it's the user's material and it needed
somewhere to live outside Downloads — treat it as background/mood reference at most, never as a
source of truth for this game's places, factions, or characters.

For this game's actual canon iconography, see `art/lore_iconography/` (the five real factions —
Noctari, Solari, Orc, Terran, Human — plus deities and artifacts) and `art/key_art/` (illustrated
locations and historical events that **are** documented in `docs/Canon_Notes.md`/`docs/Zone_Atlas.md`).

```
world_maps_and_locations/  Continent-scale world maps and named cities/regions not found in this
                            repo's Zone_Atlas (Eldoria, Ironhold, Midpoint, Deepforge, and three
                            unlabeled world-map generations).
races/                      The wider race roster (Aquari, Avari, Canari, Cervari, Crystali,
                            Felari, Lutari, Pyrari, Sylvari, Ursari, Vulpari, Whisperleaf, the
                            Sylvaneth) — not this game's Noctari/Solari/Orc/Terran/Human cast.
factions_and_events/        Continent-scale political/council art (the Beast Race Assembly, the
                            Continental Council, the Elven Diaspora, the Human Federations, the
                            Orc Dominion, the Terran Confederacy, the Terran Schism, the Beast
                            Races) — franchise-level history, not this game's timeline.
```
