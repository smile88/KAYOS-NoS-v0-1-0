# Reference Material

Third-party marketplace/asset-pack preview sheets kept as visual grounding — not authored game art,
not generated for this project, and not imported anywhere. Useful for texturing/dressing decisions
(e.g. matching the Noctari void-scholar aesthetic, or dressing ruined/rocky zones like Black Crag or
the Ashpile).

- `dark_elf_pbr_texture_sheet.png` — a "Dark Elf 3D Environment & Architecture" PBR texture sheet
  (black stone, marble, obsidian metal, void crystal, elven fabric, bone carving). Relevant to
  Noctari architecture texturing.
- `ruins_rocks_asset_pack_sheet.jpg` — a ruins/stone/rock kit preview (arches, pillars, rockpiles,
  dead trees). Relevant to ruined/wilderness zone dressing.

Neither of these is claimed to be licensed for use yet — verify before importing into
`godot/` or shipping any texture derived from them; check `docs/Asset_Sourcing_Guide.md` for the
process this repo already follows for third-party packs.
