# Building a 3D zone (the HD-2D kit)

How to build a new zone the way the Cold Open is built, using the reusable `godot/threed/` kit. The
Cold Open (`Balcony3D` + `Scriptorium3D`, driven by `ColdOpen3D`) is the reference implementation —
read those alongside this. This is the pattern Starfall and Umbraveil should follow so every zone
behaves the same for the player and the camera.

## The idea in one line

A zone is a **real 3D world of textured primitive meshes** (built procedurally in code, no hand-placed
`.tscn` layouts) that **billboard characters and props** — the existing 2D pixel sprites — stand in,
always facing an orbiting camera (the Octopath / HD-2D look).

## Conventions (do not vary these)

- **1 unit = 1 metre.** The ground is the **XZ plane**, Y is up.
- **+Z points toward the default camera** — "front". Put the thing the establishing shot looks out
  over (a rail, a skyline) at **−Z**, so the opening view faces it.
- Environments are **primitive meshes** (`BoxMesh`, `PlaneMesh`, cylinders, spheres) wearing **tiling
  textures** generated by `tools/gen_3d_textures.py` (marble, stone, city windows, star dome, …).
- Characters/props are **billboards** of the existing **48×72** sprite sheets at **`pixel_size ≈ 0.03`**
  (→ ~2.1 m tall). The sheet format is unchanged from 2D; only the framing rules changed at the pivot.

## The building blocks (all in `godot/threed/`)

| Script | Role |
|---|---|
| **`Zone3D`** | Base class for a zone. Gives you the environment toolkit: `ART`/`PLACE` texture dirs, `_tex(path)`, `_mat(tex, uv_scale, emission)`, `_box(size, pos, mat, name)`, and `drain_to_dark(over, stagger)`. Extend it and write your layout in `_ready()`. |
| **`Interactable3D`** | An `Area3D` the player examines (`display_name` + `examine_text`, or a `dialogue` JSON). Set `prop_texture` to stand a billboard prop here; leave it empty for an invisible zone on the environment. Joins group `interactable3d`. |
| **`NPC3D`** | `Interactable3D` + an animated walk-sheet billboard. `walk_toward(world_dir)` / `stop_walking()`; the walk row is chosen by projecting motion onto the camera axes, so facings stay right at any orbit angle. |
| **`Wanderer3D`** | An `NPC3D` that drifts a `roam_rect` (Rect2 on XZ), pauses, and — at a director's call — `freeze()` / `rush_to(point, over)`. Joins group `wanderer3d`. |
| **`RoomStair3D`** | An `Interactable3D` that emits `used(stair)` (with `target_room`) instead of showing text — for multi-room zones. Joins group `room_stair`. |
| **`RoomCoordinator3D`** | Owns the mechanical room change: fade, set the player at a room's spawn, move `CameraRig3D.floor_min_y` to the new floor and snap. A director sets `auto = false` and drives `go_to_room()` itself. |
| **`Player3D`** | The billboard player (`CharacterBody3D`). Camera-relative WASD; examines the nearest `interactable3d` within `interact_reach`. Wears a sheet via its `sheet` export. |
| **`CameraRig3D`** | The camera (group `camera_rig`): orbit / free-look (hold Alt) / first-person (V), wide pitch + floor guard. Actors read `forward_xz()` / `right_xz()` off it for movement and facing. |

## Recipe

**1. Textures.** If your zone needs new surfaces, add them to `tools/gen_3d_textures.py` → `godot/art/3d/`.
Reuse existing 2D prop/character PNGs from `godot/art/placeholders/` for billboards.

**2. The zone script.** Extend `Zone3D`, build the layout in `_ready()` with the inherited helpers:

```gdscript
extends Zone3D
class_name PlazaZone3D

const SPAWN := Vector3(0, 0, 2)   # where the player/coordinator drops in

func _ready() -> void:
    _build_floor()
    _build_props()

func _build_floor() -> void:
    var mat := _mat(_tex(ART + "stone.png"), 6.0)           # tiled 6×
    _box(Vector3(20, 0.4, 20), Vector3(0, -0.2, 0), mat, "Floor")   # top at y=0

func _build_props() -> void:
    var lamp := Interactable3D.new()
    lamp.display_name = "A Lamp"
    lamp.examine_text = "It hums."
    lamp.prop_texture = _tex(PLACE + "PR-021_star_lamp.png")
    lamp.position = Vector3(3, 0, -4)
    add_child(lamp)
```

Map any 2D layout you're porting with a linear transform (the Cold Open used 2D x[0,1280]→x[-9,9],
floor y→z). Keep floors' **top surface at y = 0** so billboards' feet sit on them.

**3. The scene.** Make a `.tscn` mirroring `ColdOpen3D.tscn`: a root (a director script, or plain
`Node3D`) with `WorldEnvironment`, a `DirectionalLight3D`, your zone node(s), a `Player3D` (set its
`sheet`), a `Camera3D` running `CameraRig3D` with `target_path` → the player, a `DialogueUI` instance,
and (multi-room) a `RoomCoordinator3D`. Set `run/main_scene` or hand off to it via `SceneManager.change_zone`.

**4. Multi-room** (optional). Build each room as its own `Zone3D`, offset in space (the Cold Open puts
the scriptorium 40 m down). Add a `RoomStair3D` in each, a `RoomCoordinator3D` wired to player/rig/room
nodes, and let a director drive `go_to_room()`. Give an elevated room a dark substructure box so lower
rooms don't bleed through wide/high camera angles.

**5. A director** (optional). If the zone has scripted time (a clock, beats, an event like the Silence),
write one like `ColdOpen3D.gd`: read `CameraRig3D`/`RoomCoordinator3D`/groups, drive NPCs with
`walk_toward`/`rush_to`, call `Zone3D.drain_to_dark()` to kill the lights, surface interiority through a
non-modal CanvasLayer label, and hand off with `SceneManager.change_zone(...)`.

## Verify it (discipline that has paid off here)

- **Headless logic tests** for anything with math or state (movement frame, walk-row, interaction
  reach, a director clock). **Mutation-test them** — break the code, confirm the right test goes red.
  `tests/ColdOpen3DTest.gd` is the model: it drives the whole zone end-to-end.
- **Render checks** for anything visual — they catch what code review can't (the balcony's blown-out
  city, the scriptorium window as a white slab, a room 40 m below bleeding through). Run these
  **non-headless** (a render device is required): a throwaway capture scene that instantiates the zone,
  `await`s a couple of timers, and saves `get_viewport().get_texture().get_image().save_png("user://x.png")`.

## Gotchas (save yourself the time)

- **No ceilings, front open.** A closed box fights the 360° orbit; leave rooms open-topped.
- **Billboards are unshaded** (crisp sprites) — they don't dim when you drain the world lights. Usually
  fine; know it.
- **Emissive textures blow out under bloom.** Keep `emission` energy low (≈0.1–0.3) and darken the
  albedo, or the surface becomes a featureless white slab. Raise the env `glow_hdr_threshold` so only
  true lights bloom.
- **Type your test/tool vars.** `load(...)`, `get_first_node_in_group(...)`, `child.material_override`
  and dict values are Variant — `var x := ...` fails to infer. Write `var x: T = ...`.
- **3D captures must run non-headless**, detached to a log (never piped to `grep`, which hangs):
  `( Godot res://threed/_cap.tscn >/tmp/cap.log 2>&1; echo done >>/tmp/cap.log ) &`.
- Screenshots land in `~/Library/Application Support/Godot/app_userdata/KAYOS- The Night of Silence/`.
